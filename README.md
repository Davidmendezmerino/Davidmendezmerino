## Selected projects

### [CellReview](https://github.com/Davidmendezmerino/cellreview)

An application for evaluating a blood-cell image classifier and prioritising images for review using model uncertainty. Includes saved predictions, reproducible evaluation code and an interactive review interface.

In an internal test, reviewing the top 10% of images found 194 prediction–label disagreements, compared with 54.281 on average for equally sized random selections. These are retrospective dataset results, not measured clinical outcomes.

[Live demo](https://huggingface.co/spaces/Dwagga/cellreview) · [Code and method](https://github.com/Davidmendezmerino/cellreview)

### [EHR Discharge Analyser](https://github.com/Davidmendezmerino/ehr-discharge-analyser)

A clinical NLP application that extracts seven types of follow-up action from English discharge summaries. Combines BioBERT-based sentence embeddings and multi-label classification with a FastAPI backend, a Streamlit review interface and Docker deployment.

[Live demo](https://huggingface.co/spaces/Dwagga/ehr-discharge-analyser) · [Code and setup](https://github.com/Davidmendezmerino/ehr-discharge-analyser)
